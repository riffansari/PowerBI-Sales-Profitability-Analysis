# PowerBI-Sales-Profitability-Analysis
An interactive Power BI financial performance dashboard designed to analyze sales, costs, profitability and unit sales across different business dimensions.

## Project Objective

The objective of this project was to transform financial data into an interactive dashboard that provides a clear overview of sales, costs, profitability and units sold and enables performance comparison across different business dimensions.

### Dashboard Visuals

Monthly COGS, Net Sales & Profit trend

Country-level performance matrix

KPI cards for overall financial performance

Interactive slicers for Year, Product, Country and Segment

### DAX

Created DAX measures to calculate key financial metrics, including:

Total Net Sales

Total COGS

Total Profit

Profit Margin %

Units Sold

These calculations were used throughout the dashboard to support dynamic analysis based on user-selected filters.
